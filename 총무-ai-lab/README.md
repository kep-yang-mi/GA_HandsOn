# 총무 AI LAB · 카카오 총무팀 에이전트 핸즈온

가상 총무 데이터 3종(신규입사자 장비신청, 조직개편 좌석배치, 예산정산)으로 진행하는 셀프 핸즈온 사이트입니다.

- `index.html` 안내 페이지 (셀프 핸즈온 링크 모음)
- `personal.html` Part 1 개인 실습: Step 1 스킬 · Step 2 노코드 채팅 에이전트 · Step 3 워크플로우
- `team.html` Part 2 팀 실습: Step 1 정본 지도 · Step 2 지식 카드 · Step 3 팀 에이전트·채점 · Step 4 업데이트 루틴 · 진행자 가이드
- `files/` 실습 파일 (CSV, 스킬, 규칙, 카드, 템플릿, 진행자용 정답)

정적 HTML이라 빌드가 필요 없습니다. GitHub Pages에서 저장소 루트(`/`)를 배포 대상으로 지정하면 됩니다.
