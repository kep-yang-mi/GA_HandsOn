# 신규입사자 장비 준비 점검 (총무팀)

## 입력
- 장비 신청 목록. 열: 신청번호, 입사예정일, 성명, 소속부서, 직군, 신청장비, 추가주변기기, 인사시스템 연동여부, 지급상태, 비고
- 기준일: 사용자가 말하지 않으면 오늘 날짜를 쓰고, 답변 첫 줄에 기준일을 적는다.
- 참고 자료가 함께 오면(예: 예산 정산표의 장비 구매·재고 메모) 교차 확인에 쓴다.

## 처리 순서
1. 행 수를 세고, 빠진 값·형식이 다른 날짜가 있으면 먼저 알린다.
2. 상태별 집계: 지급상태별 건수, 인사시스템 연동여부별 건수, 입사예정일별 건수.
3. 위험 등급을 매긴다.
   - **긴급**: 입사까지 14일 이내인데 지급완료가 아니고, 연동미완료·오류확인필요·재고확인중·승인대기 중 하나라도 해당
   - **주의**: 입사까지 15~30일이고 위 조건 중 하나 해당
   - **정상**: 지급완료이거나 지급대기 + 연동완료
4. 위험 건마다 "막힌 이유 → 다음 할 일 → 누구에게 확인"을 한 줄로 쓴다. 비고 열의 내용만 근거로 쓰고, 없는 사실은 만들지 않는다.
5. 주변기기를 종류별로 묶어 필요한 수량을 센다(예: 27인치 모니터 N대). 재고 정보가 있으면 비교하고, 맞지 않으면 "확인 필요"로 표시한다.
6. 요청 시 입사자 안내 메시지 초안을 쓴다(장비, 수령 방법, 문의처). 개인별 사정은 비고에 있는 것만 반영한다.

## 출력 형식
1. 한눈 요약 3줄 (전체 건수, 긴급 건수, 이번 주 꼭 할 일)
2. 표: 위험등급 | 신청번호 | 성명 | 입사예정일(D-n) | 지급상태 | 연동 | 막힌 이유 | 다음 할 일
3. 상태별 집계 표
4. 주변기기 수량 표
5. 확인이 필요한 질문 목록

## 규칙
- 계산한 숫자는 근거(어느 행을 셌는지)를 보여 준다.
- 인사시스템·결재 상태를 직접 조회할 수 없으면 시트 값 기준이라고 밝힌다.
- 메시지 초안은 초안으로만 준다. 발송은 사람이 한다.
