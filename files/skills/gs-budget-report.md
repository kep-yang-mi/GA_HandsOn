# 예산 집행 점검·보고 (총무팀)

## 입력
- 정산표. 열: 정산월, 비용항목, 세부내역, 거래처, 배정예산, 집행금액, 잔액, 결재상태, 비고
- 같은 시트 옆에 요약표(비용항목별 집행 합계·집행률)가 있으면 검산 대상으로 읽는다.
- 금액은 ₩와 쉼표를 지우고 숫자로 바꿔 계산한다.

## 처리 순서
1. 행 수와 합계를 먼저 확인한다: 배정예산 합계, 집행금액 합계, 잔액 합계. 잔액 = 배정예산 − 집행금액이 맞는지 행마다 검산한다.
2. 결재상태별(지급완료·결재완료·품의진행 등) 건수와 금액을 낸다.
3. 집행률을 **두 기준**으로 낸다.
   - 기준 A(장부 기준): 집행금액 전체 ÷ 배정예산
   - 기준 B(지급 기준): 지급완료 금액 ÷ 배정예산
   두 숫자 차이가 어느 건에서 생기는지 설명한다. 어느 기준으로 보고할지는 사용자가 정하게 한다.
4. 비용항목별·월별 집계와 집행률을 낸다.
5. 시트의 요약표가 있으면 내가 계산한 값과 대조해 일치/불일치를 표시한다.
6. 후속 처리 목록: 품의진행·결재완료 건마다 비고를 근거로 다음 할 일과 예상 시점을 적는다. 잔액이 큰 순서로 정렬한다.
7. 보고용 3줄 요약: 각 줄은 "핵심 숫자 + 의미 + 다음 행동"으로 쓴다.

## 출력 형식
1. 보고용 3줄 요약
2. 기준 A/B 집행률 표
3. 결재상태별 표, 비용항목별 표, 월별 표
4. 검산 결과(행 검산, 요약표 대조)
5. 후속 처리 목록
6. 확인이 필요한 질문 (예: 집행금액에 품의진행 금액을 넣는 것이 팀 기준인가)

## 규칙
- 모든 숫자는 원 단위까지 쓰고, 비율은 소수 첫째 자리까지 쓴다.
- 계산 근거(어느 행을 더했는지)를 표 아래에 짧게 남긴다.
- 시트에 없는 예산·실적을 추정해서 채우지 않는다.
